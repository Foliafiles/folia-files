# Community themes

Themes shared by Folia Files users. Each theme is a `.json` file exported from Settings › Themes › Export…, with a screenshot next to it (`<name>.png`).

To use one: download the `.json`, then in Folia Files open Settings › Themes › Import….

To share yours: open a pull request that adds your `.json` and a screenshot here.

Themes shared here are dedicated to the public domain under [CC0 1.0](LICENSE): anyone may use, change and share them, without asking. By opening a pull request with a theme, you agree to share it under CC0.
